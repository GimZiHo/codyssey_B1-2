# 이미 다룬 개념 기록

이 파일은 다음 학습 단계에서 생략할 수 있는 범위를 찾는 원본이다. 자료에 기록된 범위만 다룬 것으로 보며 사용자의 이해 완료를 뜻하지 않는다. 구현 완료 여부는 [진행 상태](../progress.md)를 따른다.

| 개념 또는 묶음 색인 | 다룬 범위·근거 | 자료 | 기록 구분 |
| --- | --- | --- | --- |
| B1-1 개념 001–025 | 시맨틱 HTML·CSS 배치와 스타일·이벤트·브라우저 저장소·비동기 요청·폼·Live Server 등. 정확한 생략 범위는 연결된 색인의 각 행에 한정한다. | [B1-1 학습 목록](../../../codyssey_B1-1/docs/learning/README.md) | 기존 자료 색인 확인(2026-09-26), 본문 재검토 없음 |
| HTML을 브라우저에 표시하기 | index.html 기본 구조와 탭·화면 표시 | [B1-2 001](001-index-html.md) | 기존 자료 색인 확인(2026-09-26), 적용 완료 |

B1-1 링크는 두 프로젝트를 같은 상위 디렉터리에 둔 현재 로컬 배치 기준이다. 이관 시 경로를 확인한다. 색인을 볼 수 없으면 해당 범위를 추정해서 생략하지 않는다.

새로 다룬 개념은 한 행씩 개념·범위·자료 링크·기록 구분을 추가한다. 구현 전에는 `학습자료 작성·미적용`, 구현 후에는 `적용 완료`로 구분한다. 사용자가 이미 안다고 명시한 개념은 그 범위와 `사용자 지정 생략`을 기록할 수 있으며 불필요한 자료를 새로 만들지 않는다. React·Vite·Node.js·npm·package.json 등은 기술 선택 또는 설치 이력만으로 다룬 개념에 등록하지 않는다.
